# Architecture Decision Records

This directory contains immutable records of consequential architecture decisions. ADRs use the
sequence `NNNN-short-title.md` and one of these statuses: Proposed, Accepted, Superseded, or
Rejected.

An ADR records context, the decision, alternatives, consequences, security/operational effects, and
verification implications. Proposed records do not authorize implementation. Accepted decisions that
affect requirements must also update the traceability matrix, risk register, implementation plan,
and compatibility matrix as applicable.

## Accepted records

- `0001-provider-neutral-monorepo-direction.md`
- `0002-cloud-neutral-aws-reference-deployment.md`
- `0003-provider-neutral-scm-and-model-interfaces.md`
- `0004-tenancy-data-governance-and-compliance.md`
- `0005-sandbox-approval-audit-and-quality-gates.md`

Accepted records constrain future implementation but do not by themselves grant Phase 0 build
approval.
